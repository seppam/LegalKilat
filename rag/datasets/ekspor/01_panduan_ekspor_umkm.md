## 1. TAHAPAN DASAR EKSPOR

Ekspor barang dari Indonesia mengikuti alur yang terstruktur di bawah Sistem Indonesia National Single Window (INSW). Berikut tahapan lengkapnya:

```
┌─────────────────────────────────────────────────────────────┐
│ TAHAP 1: PERSIAPAN                                            │
│ 1.1. Dapatkan NIB melalui OSS (Online Single Submission)    │
│ 1.2. Pastikan KBLI sesuai aktivitas ekspor                    │
│ 1.3. Daftarkan usaha di sistem terkait (jika perlu)         │
│ 1.4. Pahami HS Code produk via insw.go.id                    │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ TAHAP 2: KONTAK PEMBELI & NEGOSIASI                         │
│ 2.1. Cari pembeli/mitra di pasar tujuan                     │
│ 2.2. Kirim sampel produk                                     │
│ 2.3. Negosiasi harga, Incoterms, payment terms              │
│ 2.4. Tandatangani Purchase Order / Sales Contract            │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ TAHAP 3: PENGURUSAN DOKUMEN PABEAN                          │
│ 3.1. Urus dokumen情人 (invoice, packing list, COO, dll)     │
│ 3.2. Daftar Exportir registered (jika diperlukan)           │
│ 3.3. Input PEB di INSW                                       │
│ 3.4. Dapatukan PB-1 / NPE dari DJBC                          │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ TAHAP 4: PERIZINAN TERTENTU                                 │
│ 4.1. Pemenuhan Syarat Non-Tariff (perizinan khusus)         │
│ 4.2. Pemenuhan ketentuan Bea Keluar (jika ada)              │
│ 4.3. Kesehatan/Sanitasi (jika produk food/cosmetic)         │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ TAHAP 5: PENYERAHAN BARANG KE EMAS/PENGAPALAN                │
│ 5.1. Serahkan dokumen ke forwarder/pengapal                  │
│ 5.2. Barang di-container & dikirim ke pelabuhan             │
│ 5.3. Dapat BC 1.1 (Goods Declaration for Export)            │
│ 5.4. Barang dimuat ke kapal                                 │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ TAHAP 6: DOKUMEN FINAL & SETTLEMENT                          │
│ 6.1. Terima Bill of Lading (B/L) atau Sea Waybill            │
│ 6.2. Ajukan dokumen ke bank (jika LC)                        │
│ 6.3. Terima pembayaran                                        │
│ 6.4. Arsip semua dokumen untuk keperluan perpajakan         │
└─────────────────────────────────────────────────────────────┘
```

## 2. PERSYARATAN AWAL: NIB & KBLI

### 2.1 NIB (Nomor Induk Berusaha)
- Diperoleh melalui sistem **OSS (Online Single Submission)** di https://oss.go.id
- Berlaku sebagai: TDP (Tanda Daftar Perusahaan), NIK (NIK Exportir), dan akta usaha
- **Gratis** untuk semua pelaku usaha

## 3. INSW & PEB (PEMBERITAHUAN EKSPOR BARANG)

### 3.1 Apa itu INSW?
Indonesia National Single Window (INSW) adalah sistem single-window yang dikelola **Lembaga National Single Window (LNSW)**, Kementerian Keuangan RI. INSW mengintegrasikan:
- Dokumen kepabeanan
- Dokumen karantina (Quarantine)
- Dokumen perizinan (Licensing)
- Dokumen kepelabuhanan
- Dokumen lainnya terkait ekspor/impor

### 3.2 Apa itu PEB?
**Pemberitahuan Ekspor Barang (PEB)** adalah dokumen resmi yang wajib di-input oleh Eksportir ke sistem INSW sebelum barang keluar wilayah Indonesia. PEB merupakan bagian dari **BC 1.1 (Bearer Customs Declaration for Export)**.

### 3.3 Alur PEB di INSW
```
1. Eksportir LOGIN ke INSW (insw.go.id)
   └─→ Perlu NIB dan akses sebagai Eksportir

2. INPUT DATA PEB
   └─→ Isi formulir dengan data lengkap:
       - Data Eksportir (NIB, NPWP, alamat)
       - Data Pembeli/Importir (nama, alamat, negara tujuan)
       - Data Barang (HS Code, deskripsi, quantity, FOB value)
       - Data Pengangkutan (nama kapal, container number, port)
       - Incoterms (FOB, CIF, dll)
       - Negara tujuan ekspor
       - Pelabuhan muat (Indonesia) dan pelabuhan tujuan

3. UPLOAD DOKUMEN PENDUKUNG
   └─→ Invoice, Packing List, Surat Keterangan Asal (SKA/COO)
   └─→ Dokumen perizinan khusus (jika ada)

4. VALIDASI & SUBMISI
   └─→ Sistem INSW memvalidasi data
   └─→ Forward ke DJBC (Direktorat Jenderal Bea dan Cukai)

5. PENERBITAN NPE (Nota Persetujuan Ekspor) / BC 1.1
   └─→ BC 1.1 mendapat拍浮 dari DJBC
   └─→ NPE menjadi bukti legalitas ekspor

6. SERAHKAN BC 1.1 KE PENGANGKUT/PENGAKAP
   └─→ Tanpa BC 1.1 yang sah, barang tidak boleh dimuat ke kapal
```

### 3.4 Data yang Wajib Ada di PEB
| Field | Keterangan | Contoh |
|-------|-----------|--------|
| NIB Eksportir | Nomor Induk Berusaha | 81200912345678901 |
| NPWP | Nomor Pajak | 01.234.567.8-012.000 |
| HS Code | Kode tarif barang | 0901.11.10 |
| Deskripsi Barang | Uraian dalam Bahasa Inggris | Indonesia Green Coffee Beans, Arabica |
| Jumlah (Quantity) | Volume ekspor | 10,000 kg |
| Satuan | Unit of measurement | KG |
| FOB Value | Nilai Free on Board (USD) | USD 45,000 |
| Negara Tujuan | Negara importir | United States |
| pelabuhan Muat | pelabuhan ekspor | TANJUNG PRIOK |
| pelabuhan Tujuan | pelabuhan importir | LOS ANGELES |
| Incoterms | Ketentuan perdagangan | FOB |
| Nama Kapal | Nama船只 | MV. MAERSK SEAHORSE |

### 3.5 Dokumen Pendukung PEB
| No | Dokumen | Keterangan |
|----|---------|-----------|
| 1 | **Invoice (Faktur Komersial)** | Dalam USD, mencantumkan HS code, nilai, Incoterms |
| 2 | **Packing List** | Detail isi kemasan (berat kotor/bersih, jumlah koli) |
| 3 | **Surat Keterangan Asal (SKA/COO)** | Dikeluarkan oleh ICCI atau Kementerian Perdagangan |
| 4 | **Bill of Lading (B/L)** | Akan diterbitkan setelah barang dimuat ke kapal |
| 5 | **Certificate of Origin (COO)** | Untuk dapat tarif preferential FTA |
| 6 | **Phytosanitary Certificate** | Untuk produk pertanian/kopi (dari karantina) |
| 7 | **Sertifikat Kesehatan** | Untuk produk yang diatur (makanan, kosmetik) |
| 8 | **Sertifikat Standar/SNI** | Untuk produk yang wajib SNI |

## 4. SURAT KETERANGAN ASAL (SKA/COO)

### 4.1 Apa itu SKA?
Surat Keterangan Asal (SKA), atau **Certificate of Origin (COO)**, adalah dokumen yang menyatakan bahwa barang yang diekspor benar-benar berasal dari Indonesia. SKA diperlukan untuk:
- Mengajukan **tarif preferential** di negara tujuan (FTA)
- Bukti asal barang dalam perdagangan internasional

### 4.2 Lembaga Penerbit SKA
| Lembaga | Otoritas |
|---------|---------|
| **ICCI (Indonesian Chamber of Commerce & Industry)** | KADIN Indonesia |
| **APKI** | Asosiasi Kopi Khusus |
| **Disperindag** | Dinas Perdagangan daerah |
| **Kemendag** | Untuk dokumen tertentu |

### 4.3 FTA Indonesia yang Aktif
| FTA | Negara Tujuan | Manfaat |
|-----|-------------|---------|
| **AANZPA** | Australia, New Zealand | Tarif 0-5% untuk banyak produk |
| **ACIA** | ASEAN | Tarif rendah antar negara ASEAN |
| **IAI-CEPA** | India | Akses pasar India |
| **IC-CEPA** | Islandia + Swiss (EFTA) | Perlu cek detail |
| **RCEP** | 15 negara Asia-Pasifik | Perlu cek daftar produk |
| **Perjanjian bilateral** | Chile, Pakistan, MoU lain | Cek ketentuan spesifik |

## 5. PANDUAN SPESIFIK: EKSPOR KOPI

### 5.1 Syarat Ekspor Kopi
1. **NIB dengan KBLI yang sesuai**: 01240 (Kopi & Teh) atau 10771 (Industri Kopi)
2. **Registrasi Eksportir** di Ministère Pertanian / Trade (jika diperlukan)
3. **HS Code**: Gunakan 0901 untuk green bean, 0901.21 untuk roasted, 2101.11 untuk instant
4. **Phytosanitary Certificate** dari Badan Karantina Indonesia (Barantan)
5. **Fumigasi** sesuai standar negara tujuan (methyl bromide atau phosphine)
6. **Sertifikat Mutu** (SNI 01-7013-2009 atau standar pembeli)

### 5.2 Negara Tujuan Utama Kopi Indonesia
| Negara | Pasar | Catatan |
|--------|--------|---------|
| Amerika Serikat | Specialty coffee | Kenaikkan tarif, perlu FDA registration |
| Jepang | Premium green bean | Standar ketat, suka kopi arabika |
| Jerman | Komoditi | Pasar besar, blender utama |
| Italia | Espresso blends | Robusta dan arabika untuk blends |
| Malaysia | Komoditi | Dekat, tarif rendah |
| India | Emerging | Populasi besar, peluang naik |

### 5.3 Incoterms yang Umum untuk Kopi
| Incoterms | Penjelasan | Risiko Penjual | Risiko Pembeli |
|-----------|-----------|---------------|---------------|
| **FOB** (Free on Board) | Penjual tanggung sampai di kapal | Sampai kapal | Mulai dari kapal |
| **CFR** (Cost & Freight) | Termasuk ongkos kirim ke pelabuhan tujuan | Sampai kapal + freight | Mulai dari freight |
| **CIF** (Cost, Insurance, Freight) | Termasuk freight + asuransi | Sampai kapal + freight + asuransi | Mulai dari freight |
| **EXW** (Ex Works) | Penjual serahkan di tempat | Hanya di tempat | Mulai dari tempat |

## 6. PANDUAN SPESIFIK: EKSPOR BATIK

### 6.1 Syarat Ekspor Batik
1. **NIB dengan KBLI**: 10431, 14111, atau 32130
2. **Hak Cipta / Merek Dagang**: Pastikan batik dilindungi (registrasi ke DJKI/HKI)
3. **HS Code**: sesuai jenis produk (kain = 5208, baju jadi = 6204)
4. **Keterangan motif**: apakah batik tulis, cap, atau printing
5. **Label compliance**: Country of Origin = Indonesia

### 6.2 HS Code Batik untuk Ekspor
| Produk | HS Code | Deskripsi |
|--------|---------|-----------|
| Kain batik katun | 5208.xx.xx | Woven cotton fabrics |
| Kain batik sutra | 5007.xx.xx | Silk fabrics |
| Baju batik jadi (wanita) | 6204.42.10 | Pakaian jadi cotton batik |
| Blus batik | 6206.10.00 | Blus dari kapas/sutra |
| Sarung batik | 6207.xx.xx | Pakaian jadi pria |
| Kerajinan batik | 9403 / 4420 | tergantung produk |

### 6.3 Perlindungan HAKI untuk Batik
- **UU No. 28/2014 tentang Hak Cipta** melindungi motif batik
- **Daftar不通** (Common Heritage): motif batik tertentu tidak bisa diklaim pihak tertentu
- **Merek dagang**: Jika batik dengan brand spesifik, daftar merek di DJKI
- **Indikasi Geografis**: Batik Solo, Batik Pekalongan terdaftar sebagai IG

## 7. PANDUAN SPESIFIK: EKSPOR KERAJINAN

### 7.1 Kategori Kerajinan yang Umum Diekspor
| Kategori | Contoh Produk | HS Code Range |
|----------|--------------|---------------|
| Kerajinan kayu | Patung, furnitur, kotak perhiasan | 4420, 4414 |
| Kerajinan rotan/bambu | Keranjang, tas, furnitur | 4601, 4602 |
| Kerajinan kain | Taplak meja, textile art | 5805, 6302 |
| Kerajinan keramik | Vas, piring, gerabah | 6912, 6913 |
| Kerajinan logam | Perak, kuningan, perunggu | 7113, 8306 |

### 7.2 Persyaratan Umum Kerajinan
1. **NIB** dengan KBLI terkait
2. **HS Code** sesuai produk
3. **Tidak违反 CITES** (jika bahan baku dari flora/fauna dilindungi)
4. **FSC/legality** (untuk produk kayu — bukti legalitas kayu)
5. ** Fumigasi** (jika ke negara dengan karantina ketat)

### 7.3 Tips Agar Kerajinan Kompetitif
- **Custom packaging**: Sesuaikan dengan selera pasar tujuan
- **Sustainable materials**: Pasar Eropa & AS menghargai eco-friendly
- **Storytelling**: Kisah di balik produk menambah nilai jual
- **Competitive pricing**: Gunakan FTA untuk dapat preferential tariff

## 8. SISTEM PEMBAYARAN INTERNASIONAL

### 8.1 Metode Pembayaran Ekspor
| Metode | Penjelasan | Tingkat Risiko | Biaya |
|--------|-----------|---------------|-------|
| **Open Account** | Pembeli bayar setelah terima barang | Tinggi bagi penjual | Rendah |
| **Cash in Advance** | Penjual dapat bayaran sebelum kirim | Rendah bagi penjual | Sedang |
| **Documentary Collection (D/C)** | Bank acting as collecting bank | Sedang | Sedang |
| **Letter of Credit (L/C)** | Bank guarantee payment | Rendah | Lebih tinggi |
| **Standby L/C** | Guarantee/promise to pay | Rendah | Lebih tinggi |

### 8.2 Letter of Credit (L/C) — Yang Paling Direkomendasikan untuk Ekspor Baru
```
Alur L/C:
1. Buyer & Seller sepakati L/C sebagai payment method
2. Buyer membuka L/C di bank-nya (Issuing Bank)
3. L/C dikirim ke bank Penjual (Advising Bank) di Indonesia
4. Penjual kirim barang & serahkan dokumen ke bank
5. Bank verifikasi dokumen (akan dicairkan jika sesuai)
6. Penjual dapat bayaran, Buyer terima barang
```
